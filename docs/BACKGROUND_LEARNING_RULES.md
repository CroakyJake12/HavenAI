# Mandatory Background Learning, Haven Library and API Bank Rules

- Background Learning is local-first, inspectable, pausable, power/network aware and subordinate to foreground user work.
- Store structured knowledge with stable identity, category, source provenance, trust, confidence, freshness/expiry, privacy class and retention/deletion metadata.
- Deduplicate globally without erasing provenance. Failed/contradictory information remains traceable; confidence is not silently inflated.
- Per-conversation learning, explicit learning, prepared packs, just-in-time learning and interest/preference learning obey privacy settings and user deletion/forget controls.
- Haven Library exposes what is stored and why, supports search/inspection/pinning/forgetting, and never fabricates offline freshness.
- API Bank records installed App/API capability, cost, rate limits, alternatives, deprecation and offline queue policy. Keys remain in the approved secret store.
- Paid API use requires explicit permission/cost policy. Background maintenance avoids unnecessary unchanged work.
- The resource scheduler enforces foreground-first priority, battery/power/network constraints and model residency policy.
- Background execution reports real state/results/errors and must not claim completion from a queued instruction or provider acknowledgement.
