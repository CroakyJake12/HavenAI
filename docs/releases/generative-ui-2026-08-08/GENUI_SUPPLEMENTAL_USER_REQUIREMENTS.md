## Intake evidence

- Montserrat is already bundled under `src/Haven.Desktop/Assets/Fonts`, including Medium, SemiBold, Bold, ExtraBold and Black static weights plus variable fonts.
- `DefaultTheme.axaml` now applies the bundled static family globally with a SemiBold UI baseline and Bold/ExtraBold hierarchy. Explicit monospace/math/document-content fonts were classified as content exceptions; disconnected legacy editable-theme code remains scheduled for deletion behind the parity gate.
- Montserrat is not installed as a Windows system font in the current environment. The PowerPoint render therefore used a fallback; that fallback is not design intent.
